# Deep Time

Visual class investigation for Reopen the Record: how long First Nations people have lived in Australia, and how we know.
Opener · Read (scale, time walk, shrinking-land map, what is agreed) · Ask (three witnesses) · Decide · Super Sleuths · Teacher note · QR.

Live URL: https://robmac10.github.io/65000-years/ (repo RobMac10/65000-years, renamed from deep-time)
Static site, no build step. robots.txt Disallow and a noindex meta tag. 

, following the AIATSIS Code of Ethics (2020).

tools/make_map.py  builds the Sahul map paths from NOAA ETOPO1 (ERDDAP etopo180, 0.05 deg) into tools/map.json -> assets/map-data.js
tools/make_qr.py   builds assets/deep-time-qr.png (emblem in the centre, decode-checked)
tools/shots.py     headless screenshots into shots/
